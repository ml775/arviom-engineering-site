Smart AC Controller
Featuring LoRaWAN®

UC701




UC701 is a LoRaWAN® smart AC controller that supports wireless IR control of mainstream air conditioning and
PTAC systems via BMS systems or the paired Milesight WT401 thermostat. It allows automatic control through
local schedules or remote cloud systems. UC701 provides built-in sensors and multiple interfaces to integrate
with external sensors, enabling operational data collection, accurate control, and energy savings for air
conditioning systems.
Compliant with Milesight LoRaWAN® gateway and Milesight Development Platform solution, users can control the
air conditioner systems via webpage remotely.




  Features
     Provide wireless IR control without any cable connections
     Built-in IR code library compatible with mainstream air conditioner systems, with IR code learning capability
     Built-in sensor and rich external sensor inputs for accurate AC monitoring and control
     Built-in Bluetooth for easy configuration
     Support 5V DC power supply via Type-C, with an optional external battery compartment for flexible
      deployment
     Work with Milesight WT401 wireless thermostat via Bluetooth
