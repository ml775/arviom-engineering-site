## Характеристики

- **Призначення:** Виявлення витоків води та передача сигналу тривоги через LoRaWAN, з локальним сповіщенням зумером.
- **Вимірює / керує:** Наявність витоку електропровідної рідини
- **Діапазон і точність:** Спрацьовує, коли рівень рідини сягає 0,5 мм
- **Сенсор / технологія:** Невеликий водяний зонд для електропровідних рідин
- **Входи й порти:** Вбудований зумер; NFC для налаштування
- **Зв'язок:** LoRaWAN®, режими OTAA/ABP, Class A; Milesight D2D; внутрішня антена
- **Живлення:** 1 × літієва батарея CR2450 590 мА·год (безпровідне живлення)
- **Батарея:** CR2450, 590 мА·год, літієва, замінна
- **Ресурс батареї:** Близько 5,7 року (одна година витоку на тиждень, 25 °C); до 5 років за описом
- **Захист:** IP67
- **Робоча температура:** -10…+60 °C; вологість 0–100 % (без конденсату)
- **Налаштування:** Мобільний застосунок через NFC або Downlink
- **Монтаж:** Кріплення на 3M-скотч, настільне розміщення
- **Розміри:** 63 × 63 × 14 мм
- **Вага:** 36,4 г з батареєю; 29,8 г без батареї
- **Частотні плани:** CN470/IN865/RU864/EU868/US915/AU915/KR920/AS923-1&2&3&4
- **Ключові переваги:** До 5 років роботи від замінної батареї без проводів; IP67 і вбудований зумер для миттєвого локального сповіщення; Milesight D2D для прямого керування без шлюзів та налаштування через NFC
